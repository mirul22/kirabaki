# KIRABAKI Vision

## One-liner

**KIRABAKI — Your financial intelligence system.**

## Product promise

> Tell me what is happening with my money, why it matters, what I should do, and whether I am actually getting better.

## What KIRABAKI is

- A system that **understands** a financial life (not just lists transactions)
- A **Brain** of knowledge + rules + deterministic math + careful AI explanation
- A loop: find problems/opportunities → plan → recommend → act → check outcomes
- Installable as a **PWA** — the phone app until the personal MVP is proven
- Eventually: Personal → Tax → Business → Professional → Intelligence platform

## What KIRABAKI is not

| Not this | Why |
| --- | --- |
| Expense tracker | Tracking is an input, not the product |
| ChatGPT wrapper | AI is not the source of truth |
| Tax app (alone) | Tax is a later module |
| Bank / robo-advisor | Regulated; out of year-1 scope |
| “AI agent for everything” | Deterministic layers first |
| Native iOS/Android (yet) | PWA is the mobile product until MVP + gate |

**Moat layers:**

1. **Financial Knowledge Graph** — principles with provenance, not PDFs in a prompt
2. **Financial Memory** — monthly snapshots; the journey, not only today’s balance
3. **Financial Twin** — model of income, assets, debt, goals, behaviour, scenarios
4. **Decision History** — recommendation → user decision → action → outcome
5. **Malaysia financial infrastructure** — LHDN / MyInvois / tax / SME (later, versioned)

## Four-layer law (never violate)

1. **Deterministic engine** — balances, cashflow, net worth, projections = code
2. **Rules engine** — versioned, inspectable if/then advice
3. **Knowledge engine** — structured principles with source + chapter + confidence
4. **LLM** — explain and synthesise only; never invent numbers or override Layer 1

## Regulated advice boundary

| Zone | Allowed |
| --- | --- |
| Green | Education, analysis, scenarios, budgeting, tax organisation, goals, health scores |
| Yellow | General behaviour recommendations (“build emergency fund”) |
| Red | Specific regulated investment advice — separate future Licensed Advisory phase |

## Flywheels

**User flywheel:** more users → more patterns → better Brain → better insights → better outcomes → more trust → more users.

**Knowledge flywheel:** books/research/tax rules → knowledge engine → recommendations → actions → outcomes → decision intelligence → better recommendations.

## Experience

Home is **Journey**, not a dashboard. The user should feel *“okay, what’s next?”* — personal growth, not financial administration.

Five tabs: Journey · Money · Find · Learn · You. No primary Ask AI tab. AI is embedded.

Full UX/brand thesis: [UX-AND-BRAND.md](./UX-AND-BRAND.md).

## Signature experiences (build toward)

- **Journey** — path, health language, one Next Move, findings, small lesson
- **KIRABAKI FIND** — ranked, few, actionable findings (discovery, not alerts)
- **KIRABAKI PLAN** — goals with projections and “what if”
- **KIRABAKI DISCIPLINE** — commitments → check-ins → outcomes (no shame)
- **Learn** — 60–180s lessons tied to the user’s numbers
- **Monthly Review** — deterministic numbers + explained recommendations

## End game (deliberately distant)

Financial intelligence layer for people and small businesses:

Personal finance → Tax → SME finance → Accounting → Professional workflow → Platform.

The most valuable asset is not the UI. It is the **KIRABAKI Brain**: knowledge + rules + data + behaviour + goals + outcomes.
