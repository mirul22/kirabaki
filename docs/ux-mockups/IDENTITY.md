# KIRABAKI Design System v0.8

**Locked visual direction.** Refine from here. Do not explore a new palette, type family, or layout philosophy.

Craft: Izuddin / Taubat *method* (whitespace, editorial type, one dark instrument). Color and voice are KIRABAKI’s.

HTML study: [warm-intelligent/index.html](./warm-intelligent/index.html). Tokens stay in `docs/ux-mockups/warm-intelligent/tokens.css` until they are copied into `app/`.

## Type

Inter for everything you read as the product. JetBrains Mono only for amounts and the preview banner. No display serif — it made KIRABAKI look like a book app.

## Mark — presence, not a character

A single stroke (the journey) ending in a seal dot (the finding). Not a face. Not Duo. Not two squares.

Wordmark: `KIRABAKI` + a tiny descriptor (`financial intelligence` or `your financial companion`). Intelligence is **felt**, not advertised. Never `KIRABAKI AI™`.

Later, the path+dot can change by context (do not animate everywhere yet):

| Context | Presence |
| --- | --- |
| Journey | `~────●` noticing |
| Find | `──●~──` looking |
| Learn | `●────~` taking in |
| Completed | `──────●` settled |

## Voice to protect

These lines are brand, not decoration:

- Some of it stayed.
- That’s the sentence. The list can wait.
- The emergency fund grew. That’s why this month feels stronger.
- Three things. None of them a warning.
- This pace is fine. Not a race.
- A buffer, not a score.
- Those subscriptions crept up.

Philosophy: **a buffer, not a score. The list can wait. None of them a warning. This pace is fine. Not a race.**

## Next Move is discovery

The dark card is a focal point, not an alert.

Cue: **KIRABAKI found** + the path+dot. Copy stays human (“Those subscriptions crept up.”). Philosophy: three things, none of them a warning.

## What this iteration is for

More **alive**, not more colorful.

1. Personality via presence + Moments (“Nice.” / “That’s one step further.”) — quiet, then gone.
2. Next Move → Do it / Later / Not relevant.
3. Finding → Keep / Pause / Cancel → remember.
4. Goal Twin: path + “at this pace” / “if you add RM500.”
5. Learn tied to the user’s own numbers.
6. Monthly reflection (earned / kept / moved / learned / committed).

Desktop later: breathe horizontally (Journey + Found side by side). Do not become a traditional dashboard. Mobile keeps this exact calm column.

## What not to do

Do not redesign from scratch. Do not add gradients, blobs, cartoon Kira, confetti, colorful badges, giant health scores, or a new color story. Do not put a mascot on every screen.
