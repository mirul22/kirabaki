# Foundation v1 — knowledge philosophy

Living board: [STATUS.md](./STATUS.md). v0.8 stays locked.

KIRABAKI already is books + user months + Brain + one Next Move. Foundation v1 does not replace that. It records **how knowledge enters the Brain** so a later book is another source, not another feature.

## Pipeline

```text
User months
    → Layer 1 facts (lib/money)
    → Layer 2 versioned rules
    → Next Move
Principles (Layer 3) sit on the rule, not in the prompt.
```

Learn may name the source. The Next Move does not quote chapter numbers.

## Source tiers

| Tier | Meaning | Today |
| --- | --- | --- |
| official | Regulator / government education | AKPK |
| theory | Established research (unused yet) | — |
| book | Named books, paraphrased | Housel, Stanley, Collins, Robin |
| educator | Practitioner frameworks | KCLau *Millionaire Roadmap* |
| community | Forums / blogs | Never overrides official |

`kind` is the media type (`book` / `article` / `regulator`). `tier` is reliability.

Official tax and regulatory facts still come only from LHDN / BNM / SC when that phase exists. A book must not invent a rate.

## Encoded in v1

- Provenance on every source (title, author, kind, tier, year when known)
- Housel and related paraphrases already in the catalog
- Four KCLau paraphrases: saving as a pillar, income as a lever, a named destination, money needs a job
- Module titles from KCLau’s public roadmap framing — not a dump of the book

## Banned here

- YAML of every Housel chapter or KCLau module
- SIR as a 0–100 score
- Return / stocks / property / insurance engines
- Tax numbers from a book
- LLM that cites “Chapter 10”
- Twelve named engines (car, housing, portfolio…)
