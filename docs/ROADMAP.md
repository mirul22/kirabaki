# Roadmap and Gates

## Rule

**Do not advance because you are bored with the current phase. Advance because you hit a gate.**

## Gates

| Gate | Condition |
| --- | --- |
| 1 | You (founder) use KIRABAKI every week |
| 2 | 20 users use it for 30+ days |
| 3 | At least 30% complete recommended actions |
| 4 | People ask to keep using it |
| 5 | People pay |
| 6 | Users refer other people |
| 7 | Businesses pay |

Only after Gate 5+: hire heavily / invest in complex infrastructure.

## Phases (orientation — not one build)

### Phase 0 — Founder thesis (this docs pass)

Product thesis, ICP, architecture, domain model, UX/brand, agent skills, Milestone 1 brief.

### Design Milestone 0.5 — Visual language (locked v0.8)

Exploration is done. Direction: warm cream + charcoal + coral. Spec: [ux-mockups/IDENTITY.md](./ux-mockups/IDENTITY.md).

Next: refine (Next Move loop, Find decisions, presence, Moments) — then tokens into `app/` and Journey — then Milestone 1. Do not reopen A/B/C palettes.

### Phase 1 — KIRABAKI Brain

Knowledge sources, financial rules, user financial profile, decision engine, explanation engine.

### Phase 2 — Personal Alpha

Rebuild into **Journey**: health language, path, Next Move, findings, next actions.

### Phase 3 — Core financial system

Accounts, transactions, categories, recurring, assets, liabilities, net worth, cashflow, budget, goals, timeline.

### Phase 4 — KIRABAKI Advisor

Monthly review: what went well, concerns, opportunities, goal trajectory, lesson, next action.

### Phase 5 — Discipline Engine

Commitments, targets, habits, check-ins → score → adjustment. No shame language.

### Phase 6 — Opportunity Engine (FIND)

Signature feature: few ranked findings each week/month. Actionable or materially informative only.

### Phase 7 — Tax Intelligence

Receipt → OCR → category → tax relevance → user confirms. AI suggests; rules validate; user confirms.

### Phase 8 — MyInvois

Business ↔ LHDN MyInvois (submit, retrieve, search, validate, store, reconcile). Versioned integrations from day one of that phase.

### Phase 9 — KIRABAKI Business

SME financial OS with **Business Health** as the killer screen.

### Phase 10 — Professional

Accountants / bookkeepers / tax agents: clients → exceptions → reports.

### Phase 11 — Regulated financial advice

Separate strategic phase with SC licensing. **Not MVP.**

Build Personal + thin Brain first.

## 12-month plan (orientation)

| Month | Focus | Goal |
| --- | --- | --- |
| 1 | Brain + product thesis | KIRABAKI Brain v0 / Phase 0 docs |
| 2 | Personal alpha | You use it |
| 3 | Core finance | 10–20 users |
| 4 | Advisor engine | Recommendations |
| 5 | Discipline | Behaviour loop |
| 6 | Private beta | 50–100 users |
| 7 | Tax | Receipt intelligence |
| 8 | Paid launch | First RM1k MRR |
| 9 | Retention | RM3k–5k MRR |
| 10 | Business MVP | 5–10 businesses |
| 11 | Business beta | First business revenue |
| 12 | Decide | Double down / pivot / stop |

Month 12 success is not RM1m ARR. It is: **you know whether KIRABAKI deserves to become a company.**

## Do not build (until MVP proven / year-1 ban)

- Cryptocurrency, stock trading, robo-investment
- Lending, insurance marketplace, bank
- Social network, marketplace, 100 integrations
- **Native iOS/Android apps**, Capacitor/TWA “just in case”, Play/App Store wrappers
- Microservices, custom LLM, “AI agent for everything”
- 50 dashboards

Native mobile only after PWA MVP is perfected **and** a gate says the PWA is the bottleneck — see [PLATFORM-AND-SCALE.md](./PLATFORM-AND-SCALE.md).
